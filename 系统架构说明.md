# 千问离线问答系统 - 技术架构说明

## 系统概述

本系统实现了**RAG（检索增强生成）**架构，通过向量数据库检索相关文档，结合千问大模型生成准确答案。

---

## 核心流程

```
用户问题 → 向量化 → 相似度搜索 → 构建上下文 → 千问生成 → 返回答案+来源
```

## 核心模块说明

### 1. 向量化模块 (embedder.py)

**作用**: 将文本转换为向量表示

**模型**: `paraphrase-multilingual-MiniLM-L12-v2`
- 大小: ~470 MB
- 向量维度: 384
- 支持中英文
- 位置: `E:\worktool\yiliaozsk\models\paraphrase-multilingual-MiniLM-L12-v2`

**关键代码**:
```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer(model_path)
question_vector = model.encode("驻场人员当前当前1当")
# 返回: array([0.12, -0.34, 0.56, ..., 0.78], dtype=float32)
```

### 2. 向量存储 (storage.py)

**作用**: 存储和检索文档向量

**技术栈**: FAISS (Facebook AI Similarity Search)
- 索引类型: IndexFlatL2 (L2 距离，精确搜索)
- 索引文件: `data/index/faiss.index`
- 元数据文件: `data/index/metadata.json`

**数据结构**:
```json
{
  "chunks": [
    {
      "text": "驻场人员需要进行卫生学检测...",
      "filename": "情况说明.docx",
      "filepath": "E:\\worktool\\yiliaozsk\\file_info\\情况说明.docx",
      "chunk_index": 0
    }
  ],
  "documents": {
    "情况说明.docx": {
      "filepath": "完整路径",
      "total_chunks": 5
    }
  }
}
```

**关键代码**:
```python
import faiss
import numpy as np

# 加载索引
index = faiss.read_index("faiss.index")

# 搜索
question_vector = model.encode(question)
distances, indices = index.search(question_vector.reshape(1, -1), k=3)

# 返回结果
# distances: [[1.23, 2.45, 3.67]]  (相似度分数)
# indices: [[0, 5, 12]]           (文档块索引)
```

### 3. 检索引擎 (retriever.py + search_model.py)

**作用**: 整合向量化和搜索功能

**搜索方式**:
1. **语义搜索** (semantic): 基于向量相似度
2. **关键词搜索** (keyword): 精确匹配
3. **混合搜索**: 结合两者

**关键代码**:
```python
class SearchModel:
    def search(self, question, method='semantic', top_k=3, level='sentence'):
        # 1. 向量化问题
        question_vector = self.embedder.encode(question)

        # 2. FAISS 搜索
        distances, indices = self.storage.search(question_vector, top_k)

        # 3. 获取文档内容
        results = []
        for i, idx in enumerate(indices[0]):
            chunk_data = self.storage.get_chunk(idx)
            results.append({
                'text': chunk_data['text'],
                'filename': chunk_data['filename'],
                'score': float(1 / (1 + distances[0][i]))  # 转换为相似度
            })

        return results
```

### 4. 千问模型 (llm_integration.py - QwenLocalLLM)

**作用**: 生成自然语言答案

**模型信息**:
- 模型: Qwen2.5-0.5B-Instruct
- 大小: ~988 MB
- 参数量: 0.5 Billion (5亿)
- 设备: CPU
- 位置: `E:\worktool\yiliaozsk\models\Qwen2.5-0.5B-Instruct`

**关键代码**:
```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# 加载模型
model = AutoModelForCausalLM.from_pretrained(
    model_path,
    trust_remote_code=True,
    device_map="auto"
)
tokenizer = AutoTokenizer.from_pretrained(model_path, trust_remote_code=True)

# 构建提示词
text = f"""你是一个智能助手，请根据以下参考信息回答问题。

参考信息:
[来源1] 情况说明.docx: 驻场人员需要进行卫生学检测...
[来源2] 驻场人员第一.docx: 建议驻场人员在入住后7天内...

问题: 驻场人员当前当前1当

回答:"""

# 编码输入
inputs = tokenizer(text, return_tensors="pt").to(model.device)
input_length = inputs['input_ids'].shape[1]

# 生成回答
with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=512,
        temperature=0.7,
        top_p=0.9,
        do_sample=True,
        pad_token_id=tokenizer.eos_token_id
    )

# 解码输出（只取新生成的部分）
generated_ids = outputs[0][input_length:]
answer = tokenizer.decode(generated_ids, skip_special_tokens=True)
```

### 5. RAG 系统集成 (llm_integration.py - RAGQA)

**作用**: 整合检索和生成

**完整流程**:
```python
class RAGQA:
    def ask(self, question, top_k=3):
        # 1. 检索相关文档
        results = self.search_model.search(
            question,
            method='semantic',
            top_k=top_k,
            level='sentence'
        )

        # 2. 构建上下文
        context_parts = []
        sources = []

        for i, r in enumerate(results, 1):
            context_parts.append(f"[来源{i}] {r['filename']}: {r['text'][:200]}")
            sources.append({
                'filename': r['filename'],
                'filepath': r['filepath'],
                'content': r['text'][:100],
                'similarity': r['score']
            })

        context = "\n".join(context_parts)

        # 3. 生成回答
        answer = self.llm.generate(question, context)

        return {
            'question': question,
            'answer': answer,
            'sources': sources,
            'success': True
        }
```
